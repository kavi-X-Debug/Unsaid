🕶️ Unsaid — Anonymous Messaging Platform

Unsaid is a modern anonymous messaging web application.
It allows users to share one public profile link and receive anonymous messages in separate private chats, while keeping sender identities fully hidden.

The platform focuses on privacy, engagement, and simplicity, using a static profile link combined with browser-based anonymous sessions.


✨ Key Features

🔗 Single Shareable Profile Link
Users share one permanent profile link across social platforms.

👤 Anonymous Session-Based Chats 
Each visitor is assigned a hidden anonymous session, resulting in one chat per anonymous user.

🧑‍🎨 Anonymous Avatars
Anonymous users are automatically assigned a random avatar (or choose one), making chats more personal while staying anonymous.

💬 Smart Inbox
Inbox displays separate conversations, not mixed messages.

❤️ 😂 😮 Message Reactions
Users can react to anonymous messages to express emotions without replying.

📊 Anonymous Polls
Create and receive polls anonymously to boost engagement and interaction.

🔒 Privacy-First Design
No login required for anonymous users. No identity exposed in URLs or metadata.

🌗 Dark / Light Mode
Smooth theme switching with modern animations.

⚡ Real-Time Messaging
Powered by Firebase Firestore for fast and scalable updates.

📱 Responsive & Modern UI
Optimized for mobile and desktop with clean animations.


🛠 Tech Stack

Frontend: React / Next.js

Authentication: Firebase Auth

Database: Firebase Firestore

Hosting: Vercel

Styling: Modern CSS / Tailwind (if applicable)

🧠 How It Works

Users share one static profile link

Anonymous visitors receive a browser-based anonymous identity

Messages are grouped into separate chats per anonymous session

Avatars, reactions, and polls increase engagement without compromising privacy
